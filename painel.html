Etapas: entrada → saída → gate → situação real

1
Descoberta
ENTRA: catálogo da API Cebraspe + programa.json + lexico.json
SAI: provas/ID/ (PDF) e escopo/ID.jsonl (itens compatíveis)
GATE: pares prova+gabarito; item compatível sempre preservado

2
Baixada
ENTRA: URLs do CDN
SAI: prova.pdf + gabarito.pdf com hash
GATE: os dois são PDFs válidos
83 provas com PDF íntegro
3
Extraída
ENTRA: prova.pdf + gabarito.pdf
SAI: extraidos/ID.jsonl (item, contexto, enunciado, gabarito)
GATE: nº de itens = nº do gabarito; enunciado ≥25 caracteres
86 provas · vazios: 2
4
Classificada
ENTRA: pacotes/ID.md (itens + 3 códigos candidatos)
SAI: classificacoes/ID.jsonl (edital, núcleo, tags, nível)
GATE: cobre exatamente o escopo; códigos e tags válidos
135 itens classificados · 25 FORA (19%)
5
Verificada
ENTRA: pacote sem as respostas do classificador
SAI: verificacoes/ID.jsonl → comparar
GATE: edital ≥90% · núcleo ≥80% · pegadinha ≥80%
5 provas verificadas · 3 aprovadas
6
Persistida
ENTRA: classificação aprovada
SAI: banco.jsonl + nucleos.jsonl
GATE: sem duplicata (url+item ou texto igual)
150 itens no banco · 64 núcleos
7
Priorização
ENTRA: banco.jsonl
SAI: rank: núcleos ENSINAR, cobertura Good-Turing, lacunas
GATE: cobertura ≥70% para liberar a aula
ver cobertura por tema abaixo
8
Material de estudo
ENTRA: núcleos priorizados do tema
SAI: aula PDF dark + caderno (≤10 questões reais)
GATE: questão real + URL
